# ✅ To-Do App is a feature-rich Flutter task manager built with MVVM architecture and Provider state management. It supports task CRUD, undo, search, filtering, due dates, Material 3, dark mode, and Hive local storage for a fast, offline-first experience.
🚀 Getting Started

Follow these steps to set up and run the To-Do App locally.

1. Clone the Repository

git clone <repository-url>
cd <project-folder>

2. Check Flutter Installation

Verify that Flutter and the required development tools are installed:

flutter doctor

Make sure the Flutter SDK, Android SDK, and required dependencies are properly configured.

3. Install Dependencies

Install the project dependencies:

flutter pub get

4. Check Available Devices

View the connected devices and available emulators:

flutter devices

Start an Android emulator or connect a physical Android device with USB debugging enabled.

5. Run the Application

Run the Flutter application:

flutter run

To run the app on a specific device:

flutter run -d <device-id>

🛠️ Tech Stack

* Flutter & Dart — Mobile application development
* MVVM — Application architecture
* Provider — State management
* Hive — Local data persistence
* Material 3 — UI design
* Dark Mode — Theme support

✨ Key Features

* ➕ Create, edit, and delete tasks
* ↩️ Undo task actions
* 🔍 Search tasks
* 🏷️ Filter tasks
* 📅 Manage task due dates
* 🌙 Full Dark Mode support
* 💾 Local data persistence with Hive
* 📱 Offline-first functionality
